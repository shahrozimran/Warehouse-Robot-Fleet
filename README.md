# Fleetwise · Warehouse Robot Fleet

A functional local warehouse simulator with a **React frontend, Three.js digital twin, FastAPI backend, SQLite persistence, and nine MCP tools**.

Multiple robots coordinate picking, shipping, traffic conflicts, and charging.

## Open the App

The project is installed and built locally.

**Dashboard:** http://127.0.0.1:8102/

**API Reference:** http://127.0.0.1:8102/docs

## Requirements and API Keys

| Component | Requirement |
|---|---|
| Python | 3.11+ |
| Node.js | 22.12+ or 24 LTS |
| Database | SQLite |
| Graphics | Three.js and WebGL |
| LLM Key | Not required |

## Features

- **Control Room:** Manage robot fleets and scenarios.
- **3D Warehouse:** Interactive Three.js digital twin.
- **Simulation Replay:** Playback recorded robot movements.
- **Fleet Analytics:** Analyze performance and throughput.
- **MCP Integration:** Nine tools for external AI clients.
